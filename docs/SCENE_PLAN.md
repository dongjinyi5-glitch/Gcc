# 场景图层改造方案：从虚构黑帮城市 → 中国远征军战场

> **⚠️ 勘误（2026-10-23）**：本文档里各关的历史标签最初是**按美术猜的**，后来从
> `mainData` 的 build settings 场景表 + 12 张章节卡贴图拿到了权威场景名，发现
> **L3/L4/L5/L8/L13/L14 六关的标签写错了**（例如 L3 实际是 `boat` 船上而不是仰光港，
> L8 实际是 `bridge` 桥头据点而不是同古城区）。正确的关卡对应见
> **[`CHAPTERS.md`](CHAPTERS.md)**，其中最后一节给出了校正后的逐关建议。
> 下文的**方法论、面积统计、成本估算仍然有效**，只有历史原型那一列需要按 CHAPTERS.md 重排。

> **结论先说**：可以换，而且**场景层比角色层更适合做历史替换**——96% 的绘制面积不带碰撞，
> 建筑轮廓基本可以重画。1450 张不靠 AI 硬画：**162 张地标 AI 重绘（占 37% 画面）**
> + 250 张材质程序化 + 960 张道具程序化/局部替换 + 78 张只调色。
>
> **推荐先做 L3**（14 张地标 + 全关程序化），风格定了再复制。L3 实机已验证重彩版可正常加载运行。
>
> **夜景基调不用改**：这批战役的关键时刻本来就在夜间/拂晓——惠通桥 1942 年 5 月 5 日
> 清晨炸桥，松山子高地 1944 年 8 月 20 日上午 9 时 15 分起爆。

## 1. 为什么场景层比角色层更好换

### 1.1 碰撞不绑在贴图上

| 项 | 数值 |
|---|---|
| 场景纹理 | 1450 张 |
| 其中挂在**带碰撞**的 GameObject 上 | **273 张（19%）** |
| 这 273 张占绘制面积 | **17.3 / 420.4 Mpx = 4.1%** |

也就是说 **96% 的画面是纯装饰**，改轮廓不改物理。碰撞体是独立对象
（BoxCollider2D 4977 / PolygonCollider2D 568 / EdgeCollider2D 229 / CircleCollider2D 83），
不跟贴图绑定，改画面不改碰撞。

### 1.2 但有一批必须守轮廓

那 273 张里绝大多数是**平台、箱子、车辆**——玩家会站上去或撞上去。
它们的剪影必须与原图一致，否则会出现"撞到看不见的墙"或"穿过看得见的墙"。

分层的碰撞分布正好说明了这一点：

| 层 | 张数 | 绘制面积 | 占比 | 其中带碰撞 |
|---|---|---|---|---|
| T1 地标重绘 | **162** | 156.4 Mpx | **37.2%** | **5** |
| T2 材质重画 | 250 | 95.5 Mpx | 22.7% | 30 |
| T3 道具替换 | 960 | 164.2 Mpx | 39.1% | 218 |
| T4 只调色 | 78 | 4.3 Mpx | 1.0% | 20 |

**162 张地标只占 37% 的画面，却只有 5 张带碰撞。** 天际线、主建筑立面、桥、吊车、
塔——这些"决定这是哪儿"的图，几乎可以随便改。这就是历史替换的主战场。

L9 和 L10–L12 是**形制天然吻合**的两段：游戏本来就是"河谷大桥"和"竖井+地下工事"，
换成惠通桥与松山坑道，几何结构几乎不用重新设计。

### 叙事线

**第一幕 · 1942 入缅与撤退**
L3 仰光港（登陆）→ L4 腊戍（滇缅公路补给线）→ L5 曼德勒（伊洛瓦底江江防）→
L6 腾冲（滇西沦陷）→ L7 后方俱乐部（插叙，整训）→ L8 同古（城区保卫战）→
L9 惠通桥（炸桥阻敌，撤退高潮）

**第二幕 · 1944 反攻**
L10 松山坑道接近 → L11 松山地下工事 → L12 蓄水池与指挥所 →
L13 雷多中印公路工程处 → L14 密支那机场（终局）

> **关于年代顺序**：游戏关卡原型是固定的，严格年代顺序做不到。这里**形态优先于年代**。
> 若要求严格年代，L6 与 L8 可互换（腾冲↔同古），但 L6 的"老城木楼石板巷"形制更贴腾冲，
> L8 的"街区+铁桥+路障"更贴同古。**推荐保持现状**。

## 3. 四层改造法

### T1 地标重绘（162 张，AI/手绘，5–10 credits/张）

每关取**绘制面积前 14 张**——天际线、主建筑立面、桥体、吊车、塔、机库。
这些决定"这是哪儿"，其余图靠它们定调。

做法：
- 输入用该关的合成全景 + 对应格子图作参考
- 输出同尺寸 1024²（或原尺寸），**alpha 原样保留**
- 只改立面细节、材质、屋顶形制、招牌、色温——**footprint 不动**（那 5 张带碰撞的要额外核）

### T2 材质重画（250 张，程序化 + 局部修补）

`fill ≥ 0.9` 的满幅页面：砖墙、铁皮、木板、地面、天花板。

材质映射表：

| 原材质 | 换成 |
|---|---|
| 红砖墙 / 抹灰墙 | 火山石墙（腾冲）、夯土墙 |
| 木地板 / 护墙板 | 原木、竹篾编 |
| 铁皮 / 镀锌板 | 锈铁皮、油毛毡 |
| 柏油路面 | 碎石路、泥泞车辙 |
| 霓虹灯箱 | 马灯、煤油灯、火把 |

靠新写的 `restyle_scene`（按明度分墨/赭石，暗部才上石青）批处理，保留轮廓与 alpha。

### T3 道具替换（960 张，程序化 + 局部替换）

平均单张只有 0.17 Mpx（约 410×410），但**218 张带碰撞**，剪影必须守。

- 无碰撞的（742 张）：直接换，招牌、箱子、灯、桶、杂物
- 带碰撞的（218 张）：**只改材质与表面，不改外形**——箱子还是那个箱子，只是变成弹药箱/汽油桶

新增的远征军物件：滇缅公路里程碑、中正式步枪木箱、汽油桶、担架、斗笠、绑腿布、
野战电话线卷、马灯、弹药箱。

### T4 只调色（78 张，Shader/调色板）

火、烟、水、玻璃、灯光、雨雾。粒子是 ADD 混合，画进去的颜色会被吃掉，**只调色不重画**。

### UI（11 张，独立小批次）

`HudAtlasHD` / `HudAtlasSD` / `MenuAtlasHD` / `MainMenuBackground` + 4 个 Logo。
换"远征军"通用标识：斗笠、绑腿、M1 钢盔、番号布章。**不用具体党派徽记与真人形象**
（延续项目既定的虚构身份规则）。

## 4. 硬约束（不能动）

| 约束 | 原因 | 怎么守 |
|---|---|---|
| **alpha 通道** | 精灵网格与碰撞按原轮廓做的 | 重绘时 alpha 位对位保留 |
| **218 张碰撞道具的剪影** | 玩家会站上去/撞上去 | 只改表面不改外形 |
| **烘焙光照位置** | 夜景灯窗的光是画在贴图里的 | 重画必须对齐原灯位，否则夜里"没有灯" |
| **sortingOrder 层序** | 52–97 层视差，跨层会穿帮 | 换形制时不改 order |
| **精灵网格覆盖率** | 超出 tight mesh 的部分会被裁掉 | 换形制要重做多边形覆盖率验证（角色阶段做过 100% 验证，场景要重跑） |
| **水面/玻璃滚动 UV** | 靠材质 UV 动画 | 接缝必须可平铺 |
| **不改** | 碰撞、动画时序、音频、调色板动画 | 与角色阶段同一条红线 |

> **最容易翻车的是光照。** 现在每张夜景图里都烤着暖色灯窗，重画成白天或换光源位置，
> 关卡会立刻"失光"——玩家看到的是黑块，不是战场。

## 5. 风格约束（重彩 + 远征军）

- **材质优先于符号**：火山石、夯土、竹篾、锈铁、油毛毡、铅皮屋顶——用材料讲年代，不靠贴标志
- **色彩**：赭石/墨为主，石青只进阴影（远征军色带上限 石青 ≤ 0.06，见 `docs/STYLE_SPEC.md`）
- **光源色温**：暖黄（马灯/煤油灯），不是霓虹。这一步就能把"黑帮夜城"变成"战地夜晚"
- **人物**：远征军制服 + 斗笠/钢盔，日军制服，全部虚构面孔（既有规则）

## 7. 两个不推荐硬套的地方

**L7 夜总会**：找不到对应的著名战斗场景。硬套一场战役会变成"在夜总会里打松山"。
推荐改写成**蓝姆伽/雷多的军人俱乐部兼补给站**——1942 年 7 月起驻印军在蓝姆伽整训，
后方有俱乐部、食堂、补给站，室内布局完全能对上。定位为**插叙/喘息关**，不是战役。

**L14 齐柏林飞艇**：1942 年缅甸战场没有飞艇。推荐换成**密支那机场停机坪上的 C-46 运输机**
（驼峰航线主力机型），保留"巨型浮空物 + 吊舱"的构图逻辑：飞艇 → 停机中的运输机，
吊舱 → 机腹/机舱。这一张要改剪影，但它**没有碰撞**，技术上可行，需要重做 mesh 覆盖率验证。
