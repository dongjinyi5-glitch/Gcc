场景图层改造方案

从虚构黑帮城市 → 中国远征军战场 · 逐关映射 · 四层改造法 · 成本与约束

13关卡映射（12 战役关 + 菜单）
162张地标重绘（占画面 37%）
4.1%画面带碰撞，273 张需守轮廓
810–1620地标重绘 credits

可以换，而且场景层比角色层更适合换历史。273 / 1450 张纹理带碰撞， 但它们只占 4.1% 的绘制面积——剩下 96% 是纯装饰， 改轮廓不改物理。碰撞体是独立对象（Box 4876 / Polygon 566 / Edge 229 / Circle 83）， 不跟贴图绑定，所以「换画面不换物理」是成立的。

地标层几乎全自由：162 张地标（占画面 37%） 里只有 5 张带碰撞。天际线、主建筑立面、桥、吊车——这些决定「这是哪儿」的图， 基本可以随便改。

游戏关卡原型是固定的，严格年代顺序做不到， 所以形态优先于年代，排成两幕。

成本支点是 T2/T3 的程序化。T3 的 960 张若全走 AI 要 4,800–9,600 credits， 不现实。所以 restyle_scene（按明度分墨/赭石、暗部才上石青）必须先做出来—— 现成的 restyle_ink 不能直接用，实测会把砖墙变蓝绿马赛克。

3. 硬约束

约束原因怎么守
alpha 通道精灵网格与碰撞按原轮廓做重绘时 alpha 位对位保留
218 张碰撞道具的剪影玩家会站上去/撞上去只改表面不改外形
烘焙光照位置夜景灯窗的光画在贴图里重绘对齐原灯位，否则夜里「没有灯」
sortingOrder 层序52–97 层视差，跨层会穿帮换形制不改 order
精灵网格覆盖率超出 tight mesh 的部分被裁掉换形制要重做多边形覆盖率验证
水面/玻璃滚动 UV靠材质 UV 动画接缝必须可平铺

最容易翻车的是光照。现在每张夜景图里都烤着暖色灯窗， 重画成白天或换光源位置，关卡会立刻「失光」——玩家看到的是黑块，不是战场。
