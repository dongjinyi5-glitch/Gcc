## 4. 为什么全部留在原路径

六个版本**全部**保留在 `docs/` 下，未做任何归档或重命名，理由：

1. **活跃链按路径互引**：v8 正文直接引用 `docs\CAP-014_P1_PLAN_v7.md`，v8.1 引用 v8，依此类推。
   移动任一文件都会让下游正文里的路径失效。
2. **哈希链**：下游文档在头部记录了上游的 SHA-256。修改任何一版正文（哪怕只改路径）
   都会改变其哈希，破坏下游的可验证性。
3. 因此本索引只**声明**状态与链条，**不改动任何正文**。

若将来确实需要归档旧版本，必须同时满足：下游正文的路径与哈希同步更新，或保留旧路径的
跳转说明——这属于独立任务，需单独方案与验证。
