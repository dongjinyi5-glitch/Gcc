场景图层清单

Guns, Gore and Cannoli · Unity 4.3.4f1 · 全部 SpriteRenderer 场景图层 · 按关卡分批 · 附名称与样图

1450张场景纹理（去重）
420 Mpx有效绘制面积（非透明像素）
15,751渲染实例（同一张图的复用）
13关卡批次 + FX + UI

怎么读这份清单。每个关卡一张合成全景（按 sortingOrder 把该关所有 SpriteRenderer 叠起来，这就是关卡实际长什么样），加一张逐图缩略表 （名称 / 尺寸 / 引用次数，按绘制面积排序）。全景里被裁掉的极端离群物件不会出现在 缩略表之外，缩略表才是完整清单。

为什么按关卡分批。纹理名离开场景没有意义（Part3Front_12 只有 放在 level8 才读得懂），而美术本身也是按场景画的。

去重口径。389 张纹理被多个关卡共用，会同时出现在多张缩略表里； 工作量按去重的 1450 张算，不按各表相加的 2466 行算。

1. 分层结构（sortingOrder）

整数排序层，负数在最里侧（远景/视差）， 0 附近是建筑与地面，正数是前景遮挡与光照叠加。层数越多，视差越细。

5. 技术路线验证：程序化重彩为什么不能直接用

把角色用的 restyle_ink 直接套到场景层上， 默认规则是 garment（石青+石绿），砖墙会变成蓝绿马赛克。它的槽位语义是为角色设计的 （skin / garment / hat / weapon），场景需要一套自己的规则：按明度分层决定墨与赭石， 只在暗部上石青，并叠加纸纹。
