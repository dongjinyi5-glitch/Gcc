# 重彩风格验收 — 三阵营汇总

笔触指标三族共用（`SPEC_COMMON`）：重彩+中等笔触是项目级决定，
僵尸和黑帮必须用同一支笔。颜料配比按阵营分别判定（`SPEC_FACTION`），
因为三族的「衣物」语义完全不同：西服是毛料、烂衫是布、鼠怪是毛。
