# 通用历史身份方案 · 执行稿

> 本文件是 **可执行的美术规格**，不是意向书。每条描述都能直接翻成
> `restyle_ink.py` 的颜料表与笔触参数。

## 0. 与原始填写稿的差异（必读）

用户原始填写稿（`validation/roster_briefs.json`）里，有 21 条指向二战日军的
**真实个人**（多为甲级战犯），1 条指向**在任日本首相**，Vinnie 一条要求使用
本国抗日英烈的相貌。这些指向一律未采用：

- 本作含断肢、爆头、肢解等极端血腥表现，把真实人物（尤其战犯与在任外国
  政府首脑）做成被反复击杀的角色，属政治敏感内容，同时构成侮辱诽谤；
- 抗日英烈另受《英雄烈士保护法》保护，不得用于此类形象。

**保留的是**：年代、兵种、装备、服饰考据、配色意图、动作与体型。
**替换的是**：「谁的脸」→「哪类人」。全部面部为虚构设计。

原始稿保持原样存档，未做任何修改——它是用户意图的证据。

## 1. 兵种分层与配色

| 兵种 | 角色数 | 颜料策略 |
|---|---:|---|
| 远征军 | 1 | 石绿为主、赭石压黄调（HBT 橄榄绿）；唯一允许青绿积染的一档 |
| 日军将官 | 5 | 赭石打底、藤黄提金线（呢料将官服），朱红只做领章 |
| 日军佐官 | 8 | 同是国防色但压暗一档，辅色用墨而非藤黄 |
| 日军士兵 | 9 | 国防色偏绿（洗晒发青），辅色走石绿；铁帽压到墨带石绿 |
| 日本海军 | 2 | 花青与纸对分（水兵白 + 藏青），全场唯一高明度冷色块 |
| 日军军医 | 1 | 纸为主、花青压褶缝（白色军医外套），朱红只点阶级章与血迹 |
| 日本平民·劳作 | 8 | 花青为主、赭石压土色（作务衣 / 工装粗布） |
| 日本平民·浅色 | 4 | 纸为底、花青压深色制服与阴影（女学生 / 割烹着 / 白围裙） |
| 鼠怪 | 4 | 按用户要求保持原状，引擎遇到该兵种直接原样返回 |

两层正交：**faction**（人类 / 僵尸 / 鼠怪）决定「这是不是活人肉体」，**role** 决定「穿什么、什么颜色」。所以日军士兵丧尸和日军士兵本人共用同一套军服配色，但皮肤一个走活人肉色、一个走尸斑灰。

## 3. 不出现的元素

- 旭日旗、军国主义标语、天皇肖像等符号
- 任何真实人物的相貌（历史人物、在任政治人物、抗日英烈）
- 对军服的美化处理：按年代考据画，不追加荣誉性修饰

## 4. 引擎落地方式

```python
# theme_cbi.py
ROLE_OF[prefab]        -> 兵种
ROLE_KIND[role][kind]  -> (primary, secondary, allowed)
#
# restyle_ink.py
restyle(img, slot, faction=..., role=...)
```

`鼠怪` 四体在 `UNCHANGED` 集合中，`restyle()` 首行直接返回原图副本，
不经过任何像素处理——「不变」必须是可执行的，不能靠批处理脚本记得。
